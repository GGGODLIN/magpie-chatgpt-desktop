# 以 macOS ChatGPT 桌面版 CDP 內部認證連線作為單一正本並固定關閉工具呼叫

我們決定建立獨立公開外掛 `magpie-chatgpt-desktop`（供應商識別碼 `chatgpt-desktop`），透過本機 Chromium 除錯埠（CDP port 19333）連接已登入的 macOS 官方 ChatGPT 桌面版，直接由前端模組按形狀解析內部認證連線物件（具備讀取、串流送出與取消方法）並配合裝置驗證挑戰送出純文字對話（`tool_call: false`），同時讓本機既有的 sidecar 腳本改為呼叫此外掛的核心模組，不再維護多份解析器副本或採用 Playwright 獨立瀏覽器方案。

## Considered Options

- **Playwright 獨立瀏覽器自動化（操作 `chatgpt.com` 網頁）**：社群既有兩個外掛採用的做法，但在真實已登入帳號上均被網頁端的持久驗證挑戰（Turnstile 與工作量證明）擋下，無法穩定完成對話。
- **外掛與本機命令列工具各自維護一份 CDP 解析器**：桌面版平均約 11 天更新一次前端打包結構，多處副本已造成改一處漏三處的連坐故障，且公開外掛可能與自用版本產生偏移。
- **開放模擬或原生 `tool_call: true`**：內部對話介面無原生工具欄位，且多輪代理迴圈每回合重送十萬字元以上無快取上下文，違反網頁版低頻人類節奏的使用邊界。

## Consequences

- 使用者與朋友只需安裝 Magpie 與官方 macOS ChatGPT 桌面版即可使用，無須額外安裝 Python 或自製啟動器。
- 本機日常使用（如提示列白話重講與每日健檢）直接驗證同一份外掛核心，桌面版改版時只需修改並推送此單一專案，朋友端透過 Magpie 更新外掛即可同步修復。
- 僅支援 macOS 桌面版環境與純文字對話，不作為多輪讀寫檔案的主力編碼模型。
